\begin{abstract}
Measuring how system changes improve user outcomes in agent-human workflows (e.g., publish, subscribe) is critical but hard: local changes get diluted in long trajectories and goal boundaries are fuzzy. We propose a synthetic simulator based on a nested Markov chain over goals and per-goal sub-states, with goal-specific tools influencing transitions. Under a finite set of user personas, outcome probabilities, sample size, and highest-impact tool improvements are computable in closed form. Proxies that correlate with monetization and occur more often than the target outcome reduce the sample size required for a given power, enabling faster and cheaper split tests. Optimal allocation across the two arms is not 50/50: allocating more trajectories to the noisier system maximizes power and reduces cost. Expectation maximization for transition estimation corrects for label noise, so a perfect labeller is not required. Calibrating a realistic Markov chain to real trajectories yields leverage: closed-form sensitivities identify which tools and prompts have highest improvement potential, prioritizing engineering effort.
\end{abstract}
