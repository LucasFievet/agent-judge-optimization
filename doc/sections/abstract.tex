\begin{abstract}
As agents increasingly execute complex, multi-step tasks with humans---from writing and coding to legal and financial assistance---measuring how system changes improve user outcomes (e.g., publish, subscribe, cancel) becomes critical. A key challenge is that small, local changes (e.g., a better tool for one goal) get diluted in long trajectories, while goal boundaries are fuzzy and often require ad hoc clustering. We propose a synthetic simulator based on a \emph{nested Markov chain}: a top-level chain over goals (executable in arbitrary order) and a per-goal nested chain over sub-states (succeeded, continue, failed). Goal-specific tools influence the nested transition matrix, and the latent outcome of each goal feeds back into the top-level chain. This structure supports goal-aware evaluation and outcome attribution without ad hoc trajectory segmentation. We formalize problem statements for outcome attribution, goal-aware evaluation, and scalable synthetic evaluation, and we discuss connections to agent-as-judge and trajectory-level evaluation benchmarks.
\end{abstract}
